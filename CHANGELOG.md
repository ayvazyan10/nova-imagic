# Changelog

All notable changes to Imagic are documented here. The project follows
[Semantic Versioning](https://semver.org/) and this file follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

## [2.0.0] — 2026-08-22

### Added

- An authenticated, owner-scoped Nova media library with folders, search,
  filtering, sorting, pagination, uploads, reuse, rename, move, and guarded
  single or bulk deletion.
- A responsive grid/list media manager and an optional media-library picker for
  Imagic fields.
- Interactive client-side cropping before upload.
- Publishable configuration and migrations using the `imagic-config` and
  `imagic-migrations` tags.
- Configurable upload MIME, extension, byte-size, dimension, pixel, batch-size,
  visibility, thumbnail, and rate limits.
- Compatibility adapters for Intervention Image 2 and 3.
- Regression coverage for field serialization, image transformations, storage,
  validation, authorization, and media-library operations.

### Changed

- The minimum PHP version is now 8.1. Supported frameworks are Laravel 9–12
  with Nova 4–5.
- Uploads use random opaque object names instead of timestamps and original
  filenames.
- Image output is written through Laravel's filesystem abstraction, including
  remote and non-local disks.
- Standalone manager and direct field uploads default to private visibility.
  Public storage now requires an explicit configuration or field override.
  Cataloged originals and thumbnails use authenticated Nova endpoints.
- Managed uploads persist as stable `media:<uuid>` references; multiple values
  persist as JSON arrays. Legacy URL/path, JSON, CSV, and array input remains
  readable.
- Intervention Image 3 is recommended. Version 2 remains compatible for the
  2.0 transition but is upstream end-of-life.

### Fixed

- Uploading transformed images to S3 and S3-compatible disks.
- Combining an explicit filesystem disk with a custom directory.
- Filename collisions that could overwrite an earlier upload.
- Rendering and reordering multiple image values on index, detail, and form
  views.
- Saving multiple values through Laravel array/JSON/object/collection casts
  without double encoding.
- URLs that lost their scheme or host when generated by a remote disk.
- Center-crop semantics when crop coordinates are omitted.
- Nullable parameter declarations deprecated by current PHP versions.

### Security

- Media records, folders, downloads, thumbnails, mutations, and deletions are
  scoped to the authenticated Nova user.
- Uploads verify extension, detected MIME type, file size, image dimensions,
  total pixels, and per-request file count before persistence.
- Storage paths are generated by the package and normalized to prevent path
  traversal and user-controlled object keys.
- Failed writes clean up partial originals, thumbnails, and database records.
- Media API requests are rate limited.

## [1.3.0] — 2023-08-06

### Added

- Filesystem disk selection.
- Proportional resizing by width with `widen()`.

### Changed

- General code cleanup.
